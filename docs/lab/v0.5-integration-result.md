- The 3 new MCP tools (read_skeleton, read_symbols, search_saved) are listed in tools/list only with CTXPRUNE_MCP_EXTRA_TOOLS=1 (added here; the branches listed them always). Default `ctxprune mcp` tools/list sha256 identical to v0.4.0 (1de65122120c both).
- Lossless `_compact` output over 34 repo fixture/doc/source files that exist in 0.4.0: identical digest 078f786437df8b8c on v0.4.0 and the 0.5 line.
