# Shortlist: 156 in-scope ideas rated medium or large

Large first, then medium; lossless (L) before rules (R) before model (M) before measurement (X). Seed items #1-#117 are not included here.

Tags: **L** lossless, **R** deterministic rule that drops information, **M** model-based, **X** measurement/infra. `MCP` = applies to MCP tool traffic only. `busts-cache` = rewrites already-sent messages, so provider prefix caches miss from that point. Every estimate is an unverified hypothesis; 'Measured'/'Verified here' means a finder ran a quick check that was not reproduced.
